# System One latency results — batched SSM prefill (2026-10-07)

Hardware: NVIDIA GeForce RTX 4070 Ti SUPER (16 GB), Qwen3.5-0.8B Q4_K_M, dlgo-server GPU-resident, ctx 16384. Client = localhost HTTP, `bench/systemone/http_latency.py`. "Cold" = unique state prefix (exact-prefix cache miss); "warm" = exact repeat of the same request (cache hit). Matched nonce seeds; answer parity verified bit-identical for every workload (`bench/systemone/compare_results.py`).

## Final measured end-to-end (all answers bit-identical to the original engine)

| Workload | Cold before | Cold after | Speedup | Warm before | Warm after | Speedup |
|---|---:|---:|---:|---:|---:|---:|
| 1 question, ~180-token state | 293 ms | **125 ms** | 2.33× | 79 ms | **38 ms** | 2.06× |
| 3 questions, ~180-token state | 528 ms | **194 ms** | 2.72× | 309 ms | **109 ms** | 2.82× |
| 3 questions, 10.7K-token document | 17.8 s | **5.35 s** | 3.32× | 478 ms | **248 ms** | 1.92× |
| 13 questions, 10.7K-token document (GDPR) | 17.5 s | **5.88 s** | 2.97× | 1,484 ms | **798 ms** | 1.86× |

## Where the 10.9K-token cold prefill goes now (DLGO_SSM_TIME=1, full run)

| Category | Time | Share |
|---|---:|---:|
| attention (6 layers, tiled flash over growing KV) | 2.27 s | 43% |
| SSM (conv + preprocess + recurrence + norm/gate + projections, 18 layers) | 1.93 s | 37% |
| FFN (all layers) | 0.47 s | 9% |
| embedding dequant + upload | 0.06 s | 1% |
| barriers/syncs between categories | ~0.54 s | 10% |

**Attention is now the largest single cost**, not the SSM recurrence. The tiled attention shader (`gpu/shaders/attention_tiled.comp`) is barrier-bound: each 256-token KV tile runs two full 256-lane tree reductions (max and sum) with a barrier per tree step (~38 barriers/tile; the last chunk has ~44 tiles). Next lever there is a subgroup-reduction rewrite or split-KV parallelism — both change the softmax sum order, so they must be gated by the corpus accuracy gate rather than bit-parity.

The SSM recurrence is serial-chain-bound (finer value tiling, 16 vs 32 lanes, changed nothing), so the remaining structural win there is a chunked parallel delta-rule scan — also order-changing.

## What changed

1. **Fused single-token recurrence** (`gpu/shaders/ssm_delta_rule.comp`, `gpu/ssm_recurrence.go`): one dispatch replaces decay/predict/update/output; fixed the legacy shader's two math deviations (exp(alpha) decay, compensated sums). Bit-identical. `DLGO_SSM_REFERENCE=1` forces the old path.
2. **Batched SSM prefill** (`gpu/shaders/ssm_*_batch.comp`, `gpu/ssm_batch.go`, `gpu/csrc/vulkan_gpu.c`): 4 dispatches per SSM layer per chunk instead of per token — batched conv+SiLU, batched Q/K normalize + alpha/beta, multi-token fused recurrence, batched norm+gate. Opt-in via `DLGO_SSM_BATCH=1`.
3. **Value-tiled recurrence** (`ssm_recurrence_batch.comp`): one workgroup per (head, 16-wide value tile) with the state column in registers and Q/K staged in shared memory. Bit-identical; ~11% off the long-doc prefill.
4. **Recurrent-only branch restore** (`gpu/systemone_state.go`): later questions in a multi-request restore only SSM/conv state, not the whole document KV.
5. **Cancellation + serving**: `SystemOneConfig.Context` checked at chunk/question boundaries; context-aware inference-lock acquisition; responses written outside the lock; `Server-Timing: queue;dur, decision;dur` header.
6. **Profiling**: `DLGO_SSM_TIME=1` (+`DLGO_SSM_TIME_CHUNKS`) Sync-brackets embed/SSM/attention/FFN per chunk and prints a breakdown to stderr.

## Parity assessment vs Jev (typesafe.ai, advertised 70–500 ms end-to-end)

- Short states: **inside the band** — 125–194 ms cold, 38–109 ms warm, on consumer GPU hardware and a 0.8 B backbone.
- Long documents, warm cache: 248 ms (3q) / 798 ms (13q, ~61 ms/question amortized) — near the band.
- Long documents, cold: ~5.4 s — prefill-bound, dominated by attention then SSM recurrence. The two remaining order-changing optimizations (attention subgroup/split-KV reductions; chunked parallel delta-rule scan) are the path below ~2 s, each requiring the corpus accuracy gate rather than bit-parity.

Local measurements on our workloads, not a matched vendor benchmark.

## Validation

- `go test ./models/llm ./server ./cmd/systemone-train ./cmd/systemone-eval` — pass.
- `go vet` clean both tag configurations; `go test -race ./server` — pass.
- Vulkan: `TestSSMBatchGPU` (outputs/state/conv bit-identical), `TestSSMRecurrenceGPU`, `TestSSMRecurrenceModelE2E` (10,944-token hidden states bit-identical, 3 repeats), `TestSystemOneCacheBranchesE2E`, `TestSystemOneGPUCanceledBeforeInference`, `TestSystemOneSnapshot*` — pass.
- Known limitation (pre-existing): batched inference paths use FP16 KV regardless of `BytesPerElem`. Recurrent-only restore relies on external serialization (server inference gate provides it).
- Enable in production: `DLGO_SSM_BATCH=1`. Rollback: `DLGO_SSM_REFERENCE=1`.
